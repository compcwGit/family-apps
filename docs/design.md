# 디자인: 스티커북 (아이 앱 공통)

- 시안 캔버스: https://claude.ai/artifact/JLzXgasu3VzEgia6puMnev ("아이 앱 디자인 다시 하기", 2026-11-17 찬욱 승인)
- 적용 앱: 동물 친구들, 숫자 놀이, 한글 놀이, 모양 놀이, 생활 놀이 (칭찬도장은 따로 만든 시안을 씀)

## 규칙
- 굵은 잉크 테두리(#2A2840, 4px) · 납작한 색 · 아래로 밀리는 그림자(0 8px 0 잉크) → 누르면 내려감
- 종이 배경 #FFF6E5, 정답 #2FB36B. 틀려도 빨간색·벌점 없음: 카드가 기울며 흔들리고 점선이 됨
- 앱마다 대표색 하나 (`--accent`): 동물 #FF8C6B · 숫자 #FFC94A · 한글 #6EC1F5 · 모양 #B79CF7 · 생활 #63D2A1
- 글꼴: 아이 화면 Jua(@fontsource, 앱에 포함), 부모 화면 시스템 글꼴(안드로이드 = Noto Sans KR)
- 화면 틀(core `PlayShell`): 위 줄(처음으로 · 앱 이름 · 질문 말풍선+다시 듣기 · 별) + 왼쪽 놀이 목록 + 흰 놀이판
  - 폰 세로(760px 이하)에서는 놀이 목록이 위쪽 가로줄로
  - 놀이 화면의 `GameTop` 은 위 줄 말풍선 자리로 들어감
- 그림: 이모지 대신 직접 그린 캐릭터(core `Critter`, 14종: 고양이·강아지·병아리·돼지·토끼·곰·소·개구리·사자·오리·닭·양·말·코끼리)
- 맞혔을 때(core `Party`): 햇살 + 큰 별 + 캐릭터 + 말풍선("딩동댕!" / 나머지 말) + 별 +1
- 부모 화면(core `ParentPage`): 차분한 2단 카드 — 소개, 누리과정 영역, 소리(녹음/기기 음성: 녹음 파일이 있을 때만), 모은 별, 앱별 설정, 개인정보처리방침

## 아직 이모지인 곳 (그림을 더 그려야 함)
- 한글 놀이 낱말 그림 48개(듣고 찾기·첫소리 찾기), 자모 카드 낱말 그림
- 끼리끼리 물건(색 묶음), 순서대로(손 씻기 외 단계), 기분 맞추기 표정·장면
