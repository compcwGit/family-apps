# 아이용 앱 TTS 관리

이 문서는 'TTS 관리 세션'의 기준 문서입니다. 앱에서 읽어 주는 말, 만드는 방법, 현재 빠진 것을 여기서 관리합니다.
(만드는 도구 설명은 `scripts/tts/README.md`, 읽는 말 원본은 `apps/<앱>/src/voice.ts`)

## 3. 만드는 순서 (집 PC에서 Vrew)

Vrew는 집 PC에서만 쓸 수 있고 API가 없어서 반자동입니다. 집에 도착해서 "집이야"라고 하면 이 순서로 같이 진행합니다.

1. **준비**: `git checkout main && git pull && git merge origin/external`, `npm install`, `npm run voice-lines` (읽는 말 목록 최신화)
2. **대본 만들기**: `scripts\tts\Vrew대본만들기.bat --all` (전부 다시) → `scripts\tts\vrew-work\<앱>_01.txt` (한 줄 = 한 문장)
3. **Vrew에서 대본마다** (같은 목소리로 통일)
   - [새로 만들기] → [텍스트로 비디오 만들기] → txt 내용 붙여 넣기 → AI 목소리 선택
   - [파일] → [오디오 내보내기] (MP3), 자막(SRT) 내보내기
   - 두 파일을 txt와 **같은 이름**으로 `vrew-work`에 저장 (예: `lifeplay_01.mp3`, `lifeplay_01.srt`)
4. **자르기**: `scripts\tts\Vrew음성자르기.bat` 더블클릭 → 문장마다 잘라 `apps/<앱>/public/voice/`에 넣고 재생 목록 갱신
5. **확인**: `python scripts/tts/check_voices.py` → 빠진 게 없으면 커밋, 들어 보고 확인 목록의 문장은 직접 들어 보기
6. **마무리**: `git push origin main` 과 `git push origin main:external`

## 4. ⚠️ 직접 확인·결정할 부분

- **Vrew 대본 한계**: 무료 플랜은 대본 3,000자까지, 그리고 대본 한 개를 **50줄 이하**로 나눠야 합니다(200줄 대본은 시간 초과로 전부 실패). `python scripts/tts/vrew.py script --all --size 50 <앱>` 로 만드세요.
- **Vrew 크레딧**: 전체 약 150~214 크레딧이 필요합니다. 한 달 크레딧으로 모자라면 나눠서 만들거나 요금제가 필요합니다. 집 PC Vrew 계정의 남은 크레딧과 요금제를 확인해 주세요. (Vrew는 2026-04 통합 크레딧으로 바뀌었고 2026-12-01에 요금제가 또 개편됩니다. 무료 플랜 월 200 크레딧·이월 없음은 외부 블로그 기준이라 직접 확인 필요. 1 크레딧 = 100자도 앱에서 확인)
- **Vrew 목소리 선택**: 아이용이라 또렷하고 밝은 목소리가 좋습니다. 이 목소리로 앞으로 추가분도 만들기 때문에 이름을 여기 적어 둡니다. (선택한 목소리: 아오에데 Aoede, 100자당 1 크레딧)
- **먼저 샘플 확인**: 전부 만들기 전에 한 문장씩 후보 목소리를 들어 보고 정하세요. 크레딧이 한 번 쓰이면 되돌릴 수 없습니다.
- **상업 이용**: Vrew 도움말(2026-05-21)상 AI 목소리는 상업적 이용이 가능합니다. 출시 전에 약관을 한 번 더 확인해 주세요.
- **들어 보고 확인**: 두 문장이 합쳐진 줄은 글자 비율로 나눈 것이라 실제로 들어 보고 확인해야 합니다. (집에서만 가능)
- **한글 놀이 글자 2,100개**: 글자 하나(예: "가")를 Vrew가 자연스럽게 읽는지 샘플로 확인해 주세요. 이상하면 이 부분만 방식을 바꿔야 합니다.

## 5. 새 말이 생겼을 때

앱의 `voice.ts`에 말을 추가하면 → `npm run voice-lines` → 위 3번 순서로 빠진 것만 다시 만듭니다. 이 문서의 2번 표도 갱신합니다.
