# 아이용 앱 TTS 관리

이 문서는 'TTS 관리 세션'의 기준 문서입니다. 앱에서 읽어 주는 말, 만드는 방법, 현재 빠진 것을 여기서 관리합니다.
(만드는 도구 설명은 `scripts/tts/README.md`, 읽는 말 원본은 `apps/<앱>/src/voice.ts`)

## 3. 만드는 순서 (집 PC에서 Vrew)

Vrew는 집 PC에서만 쓸 수 있고 API가 없어서 반자동입니다. 집에 도착해서 "집이야"라고 하면 이 순서로 같이 진행합니다.

1. **준비**: `git checkout main && git pull && git merge origin/external`, `npm install`, `npm run voice-lines` (읽는 말 목록 최신화)
2. **대본 만들기**: `scripts\tts\Vrew대본만들기.bat` 더블클릭 → `scripts\tts\vrew-work\<앱>_01.txt` (한 줄 = 한 문장)
3. **Vrew에서 대본마다** (같은 목소리로 통일)
   - [새로 만들기] → [텍스트로 비디오 만들기] → txt 내용 붙여 넣기 → AI 목소리 선택
   - [파일] → [오디오 내보내기] (MP3), 자막(SRT) 내보내기
   - 두 파일을 txt와 **같은 이름**으로 `vrew-work`에 저장 (예: `lifeplay_01.mp3`, `lifeplay_01.srt`)
4. **자르기**: `scripts\tts\Vrew음성자르기.bat` 더블클릭 → 문장마다 잘라 `apps/<앱>/public/voice/`에 넣고 재생 목록 갱신
5. **확인**: `python scripts/tts/check_voices.py` → 빠진 게 없으면 커밋, 들어 보고 확인 목록의 문장은 직접 들어 보기
6. **마무리**: `git push origin main` 과 `git push origin main:external`

## 4. ⚠️ 직접 확인·결정할 부분

- **목소리 통일**: 기존 3,065개는 MeloTTS(D1 목소리, 조금 신나는 억양)입니다. 새 676개를 Vrew로 만들면 목소리가 섞입니다.
  → (a) 부족한 것만 Vrew로 채우고 섞임을 감수 / (b) 전부 Vrew로 다시 만들기(`Vrew대본만들기.bat --all`, 약 3,700문장 ≈ 크레딧이 훨씬 더 필요) / (c) 부족한 것도 MeloTTS D1로 만들기 중 선택
- **Vrew 크레딧**: 이번 분량은 약 72 크레딧입니다. 집 PC의 Vrew 계정에 남은 크레딧을 확인해 주세요.
- **Vrew 목소리 선택**: 아이용이라 또렷하고 밝은 목소리가 좋습니다. 고른 목소리 이름을 이 문서에 적어 두면 나중에 같은 목소리로 추가 제작할 수 있습니다. (선택한 목소리: 미정)
- **상업 이용**: Vrew 도움말상 AI 목소리는 상업 이용이 가능하지만, 플레이 스토어 출시 전에 사용 중인 목소리의 약관을 한 번 더 확인해 주세요.
- **들어 보고 확인**: 자르기 결과 중 두 문장이 합쳐진 줄은 글자 비율로 나눈 것이라 실제로 들어 보고 확인해야 합니다. (집에서만 가능)

## 5. 새 말이 생겼을 때

앱의 `voice.ts`에 말을 추가하면 → `npm run voice-lines` → 위 3번 순서로 빠진 것만 다시 만듭니다. 이 문서의 2번 표도 갱신합니다.
