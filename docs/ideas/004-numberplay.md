## 2. Claude 제안

### 실현 가능성 요약
| 항목 | 판단 | 비고 |
|---|---|---|
| 기술 (서버 없음) | ✅ 가능 | 숫자 읽는 말은 코드로 계산, 데이터 파일 없음. 오프라인 |
| 소리 | ✅ 가능 | 지금은 기기 TTS. **MeloTTS(MIT)로 mp3를 미리 만들어 넣기로 결정** (2026-11-17) → `scripts/tts/` |
| Google Play 가족 정책 | ✅ 가능 | 권한·개인정보 수집 없음. 광고 넣을 땐 monetization.md 규칙 그대로 |
| 비용 | ✅ 0원 | 개발자 계정 공유 |
| 경쟁 | ⚠️ | 비슷한 무료 앱 많음 → 우리 아이용으로 먼저, 다른 앱과 묶음/연동은 나중에 |

### 시안 v1 (구현됨)
1. **하나씩 세기**: 큰 버튼을 누를 때마다 1씩 늘고 소리로 읽음. 10마다 "잘했어요!", 100에서 축하.
   - 아래에 **10개 묶음 막대 + 낱개 점**으로 수의 크기를 보여 줌 (23 = 막대 2 + 점 3).
   - "하나 빼기", "처음부터" 버튼. 센 숫자는 기기에 저장(다시 켜도 이어서).
2. **100판**: 10×10 판, 누르면 읽어 줌. 10줄마다 색이 다르고, 센 데까지 진하게 표시.
3. **부모 화면(산수 잠금)**: 읽는 방법 선택 — `하나, 둘, 셋`(고유어, 100은 "백") / `일, 이, 삼`(한자어). 개인정보처리방침.

## 3. ⚠️ 찬욱이 직접 확인·결정할 것

- [ ] **앱 이름/패키지명** (`numberplay`는 가칭, 출시 전 확정)
- [ ] **기본 읽는 방법**: 지금은 `하나, 둘`이 기본 — 아이에게 어느 쪽부터 가르칠지
- [ ] **집 PC에 MeloTTS 설치 → 음성 생성 → 직접 들어보고 이상한 것만 `--only`로 다시** (`scripts/tts/README.md`)
- [ ] **실제 태블릿에서 TTS 확인**: "스물셋", "아흔아홉"처럼 고유어 숫자를 자연스럽게 읽는지
- [ ] **별도 앱으로 낼지 / 한글 놀이 등과 한 앱으로 묶을지**
- [ ] 광고·광고 제거 가격 (다른 앱과 통일할지)
