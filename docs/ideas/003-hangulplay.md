# 한글 놀이 (가칭, `apps/hangulplay`)

- 상태: 🔨 개발 중 (시안 v1)
- 패키지: `com.compcwgit.hangulplay` (가칭 — 스토어에 올리기 전까지는 바꿀 수 있음)
- 처음 기록: 2026-11-16

## 찬욱 아이디어 (원본)

- 유치원생 아이가 **한글을 배우는** 앱
- 안드로이드 기반으로 만들고, 시안은 아이폰에서 확인 → 수정 사항을 알려 줌
- 수익화: AdMob 광고 + 1회 결제로 광고 제거 (프로젝트 기본 방침)

## 실현 가능성 (Claude)

| 항목 | 판단 | 비고 |
|---|---|---|
| 기술 (서버 없음) | ✅ | 콘텐츠·진도 모두 기기 안, 오프라인 동작 |
| 소리 | ✅ | 지금은 기기 TTS. **MeloTTS(MIT)로 mp3를 미리 만들어 넣기로 결정** (2026-11-17) → `npm run voice-lines -w apps/hangulplay` + `scripts/tts/` |
| 따라쓰기 | ✅ | SVG + Pointer Events, 획 데이터 직접 작성(자모 24개) |
| 발음 인식 | ❌ 1차 제외 | 마이크 권한 + 아동 음성 데이터 → 가족 정책 부담 |
| 가족 정책 | ✅ | 대상 연령 "5세 이하", 학습 화면엔 광고 없음, AD_ID 권한 제거 |
| 비용 | ✅ | 개발자 계정 공유, 서버비 0 |

## 시안 v1 범위 (Claude 제안)

1. **🔤 ㄱㄴㄷ**: 자음 14 / 모음 10 카드. 누르면 "기역이에요. 기차의 기!" 읽고 그림 단어(이모지) 표시
2. **🧩 글자 만들기**: 자음 + 모음 (+ 받침 14개, 선택) 고르면 글자 조합·읽기 (ㄱ+ㅏ+ㅁ=감, 유니코드 계산)
3. **✏️ 따라 쓰기**: 한글 자모 24 + 숫자 0~9 (한글/숫자 전환). 초록 시작점·번호·점선 안내, 획 순서대로 판정 → 완료하면 ⭐ (기기에 저장)
4. **부모 화면**(산수 잠금 뒤): 진도(완료 개수, 초기화), 목소리·읽는 속도·높이 선택, 숫자 읽는 소리 선택(하나·둘 / 일·이, 기본 하나·둘), 앱 정보, 개인정보처리방침
- 친근한 말투: 칭찬("우와, 잘했어요!" 등)·격려("괜찮아, 다시 해 보자!")를 매번 다르게
- 광고·결제는 아직 없음. 쌍자음·이중모음·겹받침은 2차
- 웹 미리보기: https://compcwgit.github.io/family-apps/hangulplay/ (main·external push 시 배포)
