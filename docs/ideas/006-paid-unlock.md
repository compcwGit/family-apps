# 유료화 범위 — 기능 제한(무료) + 전체 기능 해제(유료)

- 상태: 💡 제안 (2026-11-21) — ⚠️ 아래 "찬욱이 결정할 것"이 정해지면 🔨 작업으로 쪼갬
- 대상: 아이용 앱 6개 (동물·한글·숫자·모양·생활 놀이, StampPlay)
- 기존 방침 [monetization.md](monetization.md)(광고 + 광고 제거 결제)를 이 문서가 대신함

---

## 1. 원본 아이디어 (찬욱)

- 아이용 앱 **모두 유료화**
- 무료는 **기능 제한**, 유료 결제로 **전체 기능 추가(해제)**
- 앱은 결국 **아이폰 웹앱**으로 만들 예정

---

## 2. Claude 제안 — 공통 규칙

1. **놀이 단위로 잠금**: 앱마다 처음 배우는 놀이 2~4개는 무료로 끝까지(난이도 포함) 쓰고, 나머지 놀이는 🔒.
   - 놀이 안 일부만 잠그는 것(문제 수 제한, 난이도 제한)보다 아이가 덜 헷갈리고, 구현이 간단함 (왼쪽 놀이 목록에 🔒만 붙임)
   - 무료만으로도 "쓸 만한 앱"이어야 함 → Play 최소 기능·스팸 정책, 부모 리뷰에 유리
2. **아이는 결제 화면을 못 봄**: 🔒 놀이를 누르면 아이용 안내("엄마·아빠에게 물어봐요")만 → 결제·코드 입력은 **부모 잠금(산수) 뒤 부모 화면**에만
   - Apple 어린이 카테고리: 구매 기회는 부모 확인(Parental Gate) 뒤에만 / Google 가족 정책: 과도한 상업적 유도·실수 클릭 유발 금지
3. **한 번 결제 = 영구 해제** (구독 아님). 서버가 없으므로 해제 정보는 기기에 저장
4. **광고는 넣지 않음** (제안): 아동용 광고는 수익이 낮고 정책 위험이 크며, 아이폰 웹앱에서는 AdMob 을 쓸 수 없음

## 4. 결제·해제 방법 (서버 없이)

| 어디서 | 결제 | 해제 방법 |
|---|---|---|
| **아이폰 웹앱** (홈 화면 추가) | 앱 밖 웹 결제 (아래 중 하나) | 결제하면 받는 **해제 코드**를 부모 화면에 입력 |
| 안드로이드 (Play 스토어 배포 시) | **Google Play 결제 필수** (Play 배포 앱의 디지털 상품) | Play 구매 내역으로 자동 해제 (`restorePurchases`) |
| Windows (Electron) | 웹과 같은 해제 코드 | 해제 코드 |

### 해제 코드 (서버 없이 동작)
- 찬욱 PC에만 있는 **비밀 키로 서명**한 코드 → 앱에는 확인용 공개 키만 넣음 → 인터넷 없이 앱이 진짜 코드인지 확인
- 코드에 "어느 앱(또는 전체)"을 담음 → 앱별 판매와 **전체 묶음**(가족 패스) 둘 다 가능
- 코드 만드는 스크립트는 저장소에 두되, **비밀 키는 저장소에 절대 올리지 않음**
- 한계: 코드를 남에게 알려주면 같이 쓸 수 있음 (서버가 없어서 막을 수 없음) → 저가 상품이라 감수 권장
- 아이폰: 홈 화면에 추가한 웹앱은 저장값이 유지됨. Safari 탭으로만 쓰면 오래 안 열 때 지워질 수 있음 → 부모 화면에 "코드 다시 입력" 둠

### 구현 (core 공통, 앱은 잠글 목록만 적음)
- `packages/core/src/billing.ts` → `isUnlocked(appId)` (해제 코드 / Play 구매 / 개발용 스위치)
- `PlayShell` 놀이 목록에 `locked` 표시 → 🔒 버튼, 누르면 아이용 안내 → 부모 화면으로
- `ParentPage` 에 "전체 기능" 칸: 무료/유료 놀이 목록, 구매 링크, 코드 입력, 구매 복원
- 각 앱 `App.tsx` 에는 `FREE = ['meet', 'home', ...]` 한 줄만

## 5. ⚠️ 찬욱이 직접 확인·결정할 것

- [ ] **웹 결제를 어디서 받을지** — 가장 큰 결정
  - 국내 PG(토스페이먼츠 등): 카드·간편결제 다 되지만 **사업자등록 + 통신판매업 신고**가 필요 (지금은 회사 때문에 어렵다고 함)
  - 해외 판매 대행(Merchant of Record: Lemon Squeezy, Polar 등): 개인도 가입, **한국 은행·PayPal로 정산**. 판매자 대신 세금(부가세) 처리. 대신 수수료가 높고(대략 5%+α), 결제 화면이 영어/달러 중심. **국내 소득 신고는 찬욱 몫**
  - ⚠️ 국내 사업자등록 없이 계속 판매해도 되는지, 회사 겸업 규정은 세무사·회사 규정 확인 필요 (부업 원칙: 법은 지킴)
- [ ] **가격**: 앱별 1회 구매 금액, 전체 묶음(6개) 가격 — 예: 앱당 2,900~4,900원, 전체 9,900~14,900원 (예시일 뿐)
- [ ] **앱별 판매 vs 전체 묶음만**: 묶음만 팔면 코드·화면이 가장 간단
- [ ] **무료/유료 나눈 위 표가 괜찮은지** (특히 동물 친구들 무료 6개, 색칠 도안 5개, StampPlay 무료 범위)
- [ ] **동물 친구들 첫 출시 계획**: 원래 Play 첫 심사용으로 "광고·결제 없이 완전 무료"로 정했음 → 그대로 무료로 낼지, 처음부터 잠금을 넣을지
- [ ] **광고 빼기**: 기존 방침(광고 + 광고 제거 결제)을 버리고 "기능 해제 결제"만 할지
- [ ] **한글 놀이 판매 시점**: 남은 녹음(약 1,550문장, Vrew 크레딧 12/1 회복) 뒤로 미룰지
- [ ] **이미 써 본 사람**: 지금 미리보기로 쓰던 기기도 잠기게 됨 → 출시 전이라 문제없을 것으로 보이나 확인
