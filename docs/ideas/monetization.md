# 수익화 기본 방침 (모든 앱 공통)

## 찬욱 방침 (원본)

- 기본은 **구글 광고(AdMob)** 넣기
- **유료 결제로 광고 제거** (광고 해제용 유료화)

> **2026-11-20**: 영상광고 + 결제 동시 적용 기획은 [006-ads-and-purchase.md](006-ads-and-purchase.md) 참고 (배너 대신 부모가 선택하는 영상, 결제는 부모 잠금 뒤).

## 구현 방식 (초안)

| 항목 | 방식 |
|---|---|
| 광고 | AdMob (Capacitor 플러그인 `@capacitor-community/admob`) |
| 광고 제거 결제 | Google Play 결제, **1회 구매(비소모성)** 상품 1개 |
| 구매 상태 저장 | 기기에 저장 + 앱 시작 시 Play에서 구매 내역 복원 |
| 인터넷 | 광고·결제에만 사용. 인터넷이 없어도 앱 기능은 전부 동작 |

## 아이용 앱일 때 꼭 지킬 것 (Google Play 가족 정책)

- 광고 요청에 **아동 대상 처리**(`tagForChildDirectedTreatment = true`) + 최대 광고 등급 **G**
- Play Console 타깃 연령을 아동으로만 고르면 AdMob이 가족 정책 광고만 내보냄
- **금지**: 놀이 중이나 단계 시작 때 갑자기 뜨는 전면 광고, 스플래시 전 전면 동영상,
  버튼 누를 때마다 연속으로 뜨는 전면 광고
- 아동용 광고는 채워지는 양이 적어서 **광고 수익이 낮을 수 있음** → 광고 제거 결제가 주 수익원

## 제안 (미정)

- [ ] 광고는 **아이 화면엔 넣지 않고 부모 화면(기록 보기 등)에 배너**로만?
      → 정책 위험이 거의 없고, 광고를 보는 사람이 결제하는 부모라 전환에도 유리
- [ ] **결제 버튼은 부모 잠금(산수) 뒤에만** 두기 → 아이가 실수로 결제하지 않게
- [ ] 가격 정하기 (1회 구매 금액)

## 출시 전 체크

- [ ] AdMob 계정·앱 등록, 광고 단위 ID 발급 (개발 중엔 테스트 광고 ID 사용)
- [ ] Play Console 인앱 상품 등록
- [ ] 개인정보처리방침에 광고 SDK 사용 명시, 데이터 보안 섹션 작성
