## 찬욱 결정 (원본)

- StampPlay와 **별도 앱**
- 개발자 계정 첫 심사용으로 **완전 무료**(광고·결제 없음)로 먼저 출시

## 실현 가능성 (Claude)

- 가능. 광고·결제·데이터 수집이 없으면 가족 정책 심사가 가장 단순하고, 판매자 상태도 '비판매자'와 맞음
- 위험: 버튼 몇 개짜리 앱은 Play의 **최소 기능** 기준에 걸려 거절될 수 있음 → v1에서 내용을 충분히 채움

## v1 범위 (Claude 제안)

1. 동물 12종, 누르면 통통 튀고 **음성으로 이름과 울음소리**를 읽어줌 ("강아지! 멍멍!")
   - 기기의 음성 읽기(TTS) 사용 → 녹음 파일·저작권 문제 없음, 인터넷 불필요
2. **"누구일까요?" 퀴즈 모드**: 울음소리를 듣고 동물 고르기
3. 부모 화면(산수 잠금): 앱 정보, 개인정보처리방침(수집하는 정보 없음)
4. 앱 아이콘·스플래시
5. 출시용 서명 AAB 빌드
6. 스토어 등록 정보 초안(설명, 스크린샷)

## v2: 세부 메뉴 확장 (2026-11-20, 구현됨 — `external` 브랜치)

왼쪽 놀이 4개는 그대로, 놀이마다 위쪽에 **세부 메뉴 줄**이 생김. 동물은 12 → **24마리**(새로 10마리 그림: 여우·다람쥐·호랑이·원숭이·기린·펭귄·물고기·고래·거북·문어).

| 놀이 | 세부 메뉴 |
|---|---|
| 친구 | 만나기(12마리씩 2쪽, 이름·울음소리·한마디) · 사는 곳(농장/숲/물/초원 고르기) · 아기(엄마를 누르면 아기가 나옴) · 먹이(뭘 좋아할까) |
| 퀴즈 | 소리(소리 듣고 맞히기) · 이름(이름 듣고 그림 찾기) · 누구?(얼굴 일부만 보고) · 다리(2·4·8개) |
| 그림자 | 찾기(진짜 그림자 고르기) · 맞추기(기존, 끌어다 놓기) · 누구?(까만 그림자만 보고) |
| 피아노 | 건반(동물/피아노 소리) · 따라 치기(별·나비야·작은 양) · 자유 연주(친 순서 다시 듣기) |

- 동물 정보(사는 곳·먹이·다리·한마디)는 `src/animals.ts` 한 곳. 동물을 늘리려면 `core/Critter.tsx`에 그림 + 여기 한 줄
- 퀴즈 8종은 `src/Choice.tsx` 한 틀을 같이 씀 (틀려도 벌점 없음, 맞으면 칭찬 + ⭐)
- 먹이·사는 곳 그림은 `src/Icons.tsx` (이모지 대신 직접 그림)
- 음성 문구는 24마리 × 여러 문장으로 늘어 **75 → 464개**. 새 문구(389개)는 녹음 전까지 기기 음성(TTS)으로 읽음
