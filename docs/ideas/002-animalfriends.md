- 상태: 🔨 개발 중
- 패키지: `com.compcwgit.animalfriends`
- 처음 기록: 2026-11-16

## 찬욱 결정 (원본)

- StampPlay와 **별도 앱**
- 개발자 계정 첫 심사용으로 **완전 무료**(광고·결제 없음)로 먼저 출시

## 실현 가능성 (Claude)

- 가능. 광고·결제·데이터 수집이 없으면 가족 정책 심사가 가장 단순하고, 판매자 상태도 '비판매자'와 맞음
- 위험: 버튼 몇 개짜리 앱은 Play의 **최소 기능** 기준에 걸려 거절될 수 있음 → v1에서 내용을 충분히 채움

## v1 범위 (Claude 제안)

1. 동물 12종, 누르면 통통 튀고 **음성으로 이름과 울음소리**를 읽어줌 ("강아지! 멍멍!")
   - 기기의 음성 읽기(TTS) 사용 → 녹음 파일·저작권 문제 없음, 인터넷 불필요
2. **"누구일까요?" 퀴즈 모드**: 울음소리를 듣고 동물 고르기
3. 부모 화면(산수 잠금): 앱 정보, 개인정보처리방침(수집하는 정보 없음)
4. 앱 아이콘·스플래시
5. 출시용 서명 AAB 빌드
6. 스토어 등록 정보 초안(설명, 스크린샷)
