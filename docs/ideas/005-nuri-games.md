# 누리과정 놀이 묶음 (놀이 12개 → 앱 5개에 나눠 넣기)

- 상태: 🔨 개발 중 (시안 v1, 2026-11-17)
- 새 앱: `apps/shapeplay` 모양 놀이 (가칭, `com.compcwgit.shapeplay`), `apps/lifeplay` 생활 놀이 (가칭, `com.compcwgit.lifeplay`)
- 웹 미리보기: https://compcwgit.github.io/family-apps/ (external push 시 배포)

---

## 1. 원본 아이디어 (찬욱)

- 유치원생용 앱을 **한국 유치원 교육과정(누리과정)에 맞게** 구성하고 싶음
- 아이 정보는 **수집하지 않고**, **로컬에서만** 동작하는 간단한 공부·놀이 앱
- Claude가 제안한 놀이(도형 맞추기 등)를 **전부** 만들기로 함
- 앱은 **주제별로 묶어서** 나누기로 결정 (놀이마다 앱 하나 ❌, 한 앱에 전부 ❌)

---

## 2. Claude 제안

### 근거: 2019 개정 누리과정 (만 3~5세, 2020년 3월 시행)
5개 영역 — 신체운동·건강 / 의사소통 / 사회관계 / 예술경험 / 자연탐구.
나이별 구분이 없으므로 **난이도는 앱에서 직접 설계** → 별이 모이면 조금씩 어려워지게 함.
유보통합으로 0~5세 통합 교육과정이 나올 예정이라, 영역 연결은 부모 화면 문구로만 두고 코드에 박지 않음.

### 왜 주제별로 묶나
- 개인 개발자 계정은 **앱마다** 테스터 12명 × 14일 비공개 테스트를 통과해야 프로덕션 출시 가능
- 놀이 1개짜리 앱은 Play **스팸·최소 기능** 정책에 걸릴 위험 → 앱마다 놀이 3~5개로 내용을 채움

### 나눈 결과 (구현됨)

| 앱 | 추가한 놀이 | 누리과정 영역 |
|---|---|---|
| 동물 친구들 | 👤 그림자 맞추기 (동물을 그림자에 끌어다 놓기), 🎹 동물 피아노 (도~도, 피아노/동물 소리) | 자연탐구, 예술경험 |
| 숫자 놀이 | 🍎 몇 개일까? (눌러서 세기 → 숫자 고르기, 1~5 → 1~10), 🐻 크기 순서 (작은/큰 것부터, 3→5개), 🔁 다음은 뭘까? (AB → AAB·ABB·ABC) | 자연탐구 |
| 한글 놀이 | 👂 듣고 찾기 (낱말 듣고 그림 고르기), ㄱ 첫소리 찾기 (자음으로 시작하는 그림 고르기) | 의사소통 |
| **모양 놀이** (새 앱) | 🔺 도형 맞추기 (6가지 도형), 🧺 끼리끼리 (색/모양으로 바구니에 나누기), 🎨 색칠 놀이 (그림 15개, 기기에 저장), 🧩 칠교놀이 (도안 5개: 나무·물고기·집·배·네모, 조각 3→7개), 🃏 카드 짝 찾기 (3→4→6쌍), 🔢 점 잇기 (7개 그림), 🔍 다른 그림 찾기 (2→3군데), 📦 위치 놀이 (위·아래·안·옆) | 자연탐구, 예술경험 |
| **생활 놀이** (새 앱) | 🧼 순서대로 (손 씻기·이 닦기·길 건너기·밥 먹기·잠자기·외출하기), 😊 기분 맞추기 (상황 19개, 감정 6개), 🚦 안전할까요 (⭕❌ 12개), 💬 뭐라고 말할까요 (고운 말 10개), 🧸 제자리에 정리해요, ☔ 날씨에 맞게 입어요, 🚒 누가 도와줄까요 (8개) | 신체운동·건강, 사회관계 |

### 디자인: 점토 테마 (2026-11-20, 찬욱 결정: 모든 앱)
- 찬욱이 보낸 파스텔 3D 점토 느낌 시안 → `core/clay.css` (잉크 테두리 대신 부드러운 그림자·하이라이트, 파스텔 배경 얼룩, 카드 색 번갈아)
- 이모지·동물 캐릭터·칭찬 별 → **Microsoft Fluent Emoji 3D (MIT)** 그림. `npm run emoji` 가 앱에서 쓰는 그림만 `public/emoji/` 로 넣음 (그림이 없으면 글자 이모지)
- 부모 화면에 "오픈소스" 칸(MIT 표시) 자동 추가. 칭찬도장의 도장은 잉크 도장 모양 그대로
- 대표 캐릭터(우리 앱만의 마스코트)는 나중에

### 공통 원칙
- 틀려도 벌점 없음: 살짝 흔들리고 격려("다시 해 볼까?"), 맞으면 칭찬 + ⭐
- 별은 놀이별로 기기 안에만 저장 (부모 화면에서 초기화)
- 인터넷·권한·개인정보 수집 없음 → 부모 화면에 개인정보처리방침 포함

### core 에 새로 만든 것 (두 앱 이상에서 씀)
- `useDrag` — 끌어다 놓기 (Pointer Events, 마우스·터치)
- `DragMatch` — 끌어다 맞추기 놀이 (도형 맞추기, 그림자 맞추기)
- `useFeedback`, `useSay`, `GameTop`, `Party`, `useStars` — 놀이 공통 반응·별
- `talk` — 조사(은/는, 을/를, 이/가, 예요/이에요), 칭찬·격려 문구, `shuffle`, `pick`
- `ParentPage` — 부모 화면 공통 (앱 소개, 누리과정 영역, 별 초기화, 개인정보처리방침)
- 기존 앱의 ParentInfo·말투 코드는 그대로 둠 (나중에 손볼 때 core 로 옮기면 됨)

## 3. ⚠️ 찬욱이 직접 확인·결정할 것

- [ ] **새 앱 이름/패키지명**: `shapeplay` 모양 놀이, `lifeplay` 생활 놀이 (가칭 — 스토어에 올린 뒤엔 바꿀 수 없음)
- [ ] **태블릿에서 끌어다 놓기**: 손가락으로 잘 끌리는지, 조각·구멍 크기가 적당한지 (브라우저 마우스로만 확인함)
- [ ] **기분 맞추기 정답**: 감정에는 정답이 하나가 아닐 수 있음. 지금은 틀려도 "그럴 수도 있어요"로 부드럽게 넘어감. 상황·문구가 괜찮은지 확인
- [ ] **순서대로 내용**: 손 씻기 4단계 등 집에서 가르치는 순서와 같은지 (예: 밥 먹기 "잘 먹겠습니다" 단계)
- [ ] **그림**: 지금은 이모지(기기마다 모양이 조금 다름, 🪥 등 최신 이모지는 오래된 기기에서 안 보일 수 있음). 출시 전에 직접 그림/CC0/유료 에셋으로 바꿀지
- [ ] **끼리끼리 색 구분**: 이모지 색이 기기마다 다를 수 있음 (🦋 파란색 등) → 태블릿에서 헷갈리는 것 빼기
- [ ] **어느 앱부터 출시할지**: 앱마다 비공개 테스트 14일이 따로 필요하므로 순서를 정해야 함
- [ ] **생활 놀이 새 내용 확인** (2026-11-20 추가): 안전 규칙 문구(겁주지 않게), 119·112 안내, 장화가 등산화 모양(🥾)인 것, 옷장 그림(🚪)
- [ ] **동물 피아노 동물 소리 모드**: 기기 TTS 는 반응이 느려서 빠르게 치면 소리가 끊김 → 녹음 파일(MeloTTS 등)로 바꿀지
