# 칭찬도장 모험 게임

- 상태: 🔨 개발 중 (도장판 + 약속 + 칭찬 기록, 2026-11-17)
- 대상: 유치원생 아이 (태블릿) + 부모
- 처음 기록: 2026-11-16
- 앱 이름: **StampPlay** / 패키지: `com.compcwgit.stampplay` (찬욱 결정, 2026-11-16)

## 찬욱 아이디어 (원본)

- 아이가 **칭찬도장 / 반성도장**을 받으면서 **모험을 하는 게임** 같은 앱
- 도장은 **부모님이 찍어줌**
- 부모 확인은 요즘 앱처럼 **산수 문제**로. 유치원생이라 이 정도면 충분할 듯
- (2026-11-17) 도장을 다 모았을 때의 **약속**을 정하고 싶음 — 예: 15개 모으면 장난감 사주기
- (2026-11-17) **아이 화면에서도 칭찬판 기록(히스토리)**을 보여 주고 싶음
- (2026-11-17) 과거 도장판도 **눌러서 열어 보기**, 각 도장을 누르면 **찍은 일시** 보기
- (2026-11-17) **부모 화면에서도 아이와 같은 도장판 화면에서 도장을 찍어 주기**
- (2026-11-17) 부모 화면 도장판에서 **찍은 도장을 바로 지우기**, 하단 도장 목록은 없애고 **도장을 누르면 내역**
- (2026-11-17) **부모 모드에서도 과거 도장판 보기**
- (2026-11-17) 기능은 그대로 두고 **디자인은 시안("칭찬도장 앱 시안" 캔버스)으로 마무리**
- (2026-11-17) **캐릭터 고르기**: 곰, 토끼, 호랑이, 기린, 공룡, 상어 중에서. 시안(아티팩트)으로 먼저 보고 진행. 기본 모습에서 **손에 든 도장은 빼기**
- (2026-11-17) 칭찬도장 내용을 **직접 만들기**. 칭찬도장의 기본 그림은 **"참 잘했어요" 도장**

## 구현됨 (Claude, 2026-11-17)

- **약속**: 부모 화면에서 `− N개 +` (1~30) + "무엇"(글자)을 정함 → 도장판 칸 수가 N개로 바뀌고 아이 화면 위에 `🎁 15개 모으면 장난감 사주기`
  - 약속은 도장판마다 따로 저장. 다음 도장판은 마지막 약속을 그대로 이어받음(바꾸면 그때부터 적용)
  - 지금 도장판이 다 찼으면 바꾼 약속은 다음 도장판에 적용
  - 다 모으면 `🎉 도장판 완성! 약속: 장난감 사주기 🎉`
  - 약속을 안 정했던 예전 도장판은 10칸 그대로
- **칭찬 기록 (아이 화면)**: `📖 칭찬 기록` 버튼 → 도장판별 카드(최근 판이 위): 번호, 완성/모으는 중, 약속, 받은 도장 그림, 날짜
- **지난 도장판 열기**: 칭찬 기록의 카드를 누르면 그 도장판 화면
- **도장 일시**: 도장판(지금·지난)에서 도장을 누르면 아래에 `이름 · 11월 17일 (화) 오전 8:18`
- **칭찬도장 만들기 (부모 화면)**: `✏️ 칭찬도장 만들기·지우기` → 그림 고르기(첫 칸이 기본 "참 잘했어요" 도장) + 이름 → `도장 추가`. 편집 중에 도장을 누르면 지움
  - 도장 그림은 찍을 때 기록에 같이 저장 → 도장 종류를 지우거나 바꿔도 이미 찍은 도장은 그대로
  - 처음 기본 목록(정리정돈·양치하기 …)은 그대로 두고, 지우거나 추가할 수 있음
- **부모 화면 도장판에서 찍기**: 도장 종류를 고르고(빨간 테두리) → 아이 화면과 같은 도장판의 빈 칸을 누르면 "쾅" 애니메이션으로 찍힘. 다음 칸이 깜빡여 안내
  - 도장은 순서대로 채워짐(어느 빈 칸을 눌러도 다음 칸에 찍힘). 지금 판이 다 찼으면 다음 빈 판이 나옴
- **부모 화면 지우기**: 도장판의 도장을 누르면 내역(이름·일시) 옆에 `지우기`. 하단 "최근 기록" 목록은 없앰
  - 판을 다 채우면 다 찬 판(지우기 가능)과 그 아래 다음 빈 판을 함께 보여 줌
- **부모 모드 지난 도장판**: 부모 화면 `📖 지난 도장판 보기` → 칭찬 기록 → 판 열기. 여기서는 도장을 눌러 지울 수 있음, 닫으면 부모 화면으로
  - 도장은 순서대로 판에 채워지므로 지난 판에서 지우면 다음 판의 첫 도장이 앞 판으로 당겨짐
- **디자인 시안 적용** (Claude Design 캔버스 "칭찬도장 앱 시안")
  - 색: 크림 바탕 #FFF6E8, 진갈색 글자 #3A2A1F, 도장 잉크 빨강·파랑·초록 / 글꼴: Jua(제목·도장), Gowun Dodum(본문) — OFL, 앱에 포함(@fontsource)
  - 도장: 두 겹 원 테두리 + 잉크 색 + 칸마다 살짝 기울임. 칭찬도장 만들 때 잉크 색도 고름(기본 빨강)
  - 캐릭터 **꾹이**(도장 든 아기곰): 아이 화면(기본), 부모 확인(눈 가리기), 도장 찍힘(기뻐하기)
  - 아이 화면: 도장판 + 오른쪽 선물 카드(약속, 모은 개수, 진행 막대, 꾹이 말풍선). 위에 `칭찬 기록`, `엄마·아빠`
  - 부모 확인: 곱셈 문제 + 숫자 키패드 (StampPlay 전용. 다른 앱은 core 부모 잠금 그대로)
  - 부모 화면: 도장판 + 오른쪽 "도장 고르기", 아래 약속 카드. 폰 세로에서는 도장 고르기가 위로
  - **도장 찍힘** 화면 새로 추가: 부모 화면에서 도장을 찍고 아이 화면으로 돌아오면 한 번 보여 줌
  - 태블릿 가로(1280×800) 기준, 폰 세로(390)에서도 한 줄로 쌓여 보임
- **캐릭터 고르기**: 부모 화면 맨 아래 `함께할 친구`에서 6종 중 선택(기본 곰). 아이 화면·부모 확인·도장 찍힘에 고른 친구가 나옴
  - 모두 같은 몸 틀(기본·기뻐하기·눈 가리기)에 귀·무늬·색만 다르게 그림. 기본 모습은 양팔을 내린 모습(도장 안 듦)
  - 시안 캔버스 "6 · 캐릭터 고르기" 보드와 앱이 같은 그림(`src/Mascot.tsx`)
- ⚠️ 정할 것: 약속을 지켰는지 표시(부모가 "약속 지켰어요" 체크)가 필요한지 / 기록에서 도장 이유 글자까지 보여 줄지

## 정리한 구조 (초안)

### 아이 화면
- 모험 지도: 도장을 받을 때마다 캐릭터가 한 칸씩 전진
- 도장판: 받은 도장을 모아 보는 화면
- 도착 지점마다 작은 보상 (새 친구 캐릭터, 배경, 축하 애니메이션)

### 부모 화면 (산수 잠금 뒤)
- 칭찬도장 / 반성도장 찍기
- 이유 선택: 정리정돈, 양치, 인사, 동생 돌보기 … (직접 추가 가능)
- 기록 보기: 날짜별 도장 내역

### 부모 잠금
- 한 자리 덧셈 2개 이상 또는 두 자리 덧셈 (예: 14 + 9)
- 매번 랜덤 출제, 틀리면 아이 화면으로 돌아가기

## 기술 메모

- 인터넷 없이 동작, 데이터는 태블릿 안에 저장 (Dexie.js / IndexedDB)
- 광고·추적 없음 → Play 스토어 가족 정책에 유리
- 기존 로드맵의 "칭찬 스티커판 + 부모 잠금"(5–6주차)을 이 앱으로 확장하는 형태

## 수익화

- 공통 방침 적용: 광고 + 광고 제거 결제 → [monetization.md](monetization.md)

## 최소 버전(MVP) 후보

1. 부모 잠금(산수) → 칭찬도장 찍기
2. 도장 수만큼 지도에서 캐릭터 전진
3. 도장 기록 저장
