## Play Console 설문 답 (참고)
| 항목 | 답 |
|---|---|
| 카테고리 | 교육 (또는 앱 > 교육) · 태그: 유아, 동물 |
| 타깃 연령 | **만 5세 이하**만 선택 (→ 가족 정책 적용) |
| 광고 포함 | 아니요 |
| 인앱 구매 | **있음** — 수익 창출 설정 → 인앱 상품 → 상품 ID `animalfriends_full` (1회 구매), 가격 직접 설정 |
| 데이터 보안 | 수집하는 데이터 **없음**, 공유하는 데이터 **없음** (구매는 Google Play 가 처리, 기기 안 저장은 수집 아님) |
| 앱 액세스 | 로그인 없음. 일부 놀이는 인앱 구매로 열림 (부모 화면은 산수 문제: 화면에 문제가 나옴) |
| 콘텐츠 등급(IARC) | 폭력·공포·성적·언어·도박·사용자 간 상호작용·위치 공유 모두 "아니요", **디지털 구매는 "예"**(인앱 구매) → 전체 이용가 예상 |
| 뉴스 앱 / 정부 앱 / 금융 기능 / 건강 앱 | 아니요 |
| 권한 | 인터넷 외 없음 (Capacitor 기본 INTERNET 권한은 있음 — 실제로 쓰지 않음) |
